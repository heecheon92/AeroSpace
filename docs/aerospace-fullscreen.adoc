// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

Switching to a different tiling window within the same workspace while the current focused window is in ordinary fullscreen mode results in the fullscreen window exiting fullscreen mode.

`--centered` uses the fullscreen state while displaying a centered window.
Its width and height default independently to 50% of the selected monitor rectangle and can be set with `--width` and `--height`.
Percentages must include `%`, may contain decimals, and must be greater than 0% and no greater than 100%.
The selected monitor rectangle includes outer gaps unless `--no-outer-gaps` is specified.
The window keeps its place in the tiling tree, and leaving centered fullscreen restores that tile.
For tiled windows, unlike ordinary fullscreen, centered fullscreen remains active when focus moves to another window or workspace.
Use `fullscreen off` or toggle an identical centered size to exit; requesting different dimensions or outer-gap handling retargets the centered window instead.
Centered fullscreen transitions are disabled by default.
`--animation on` enables transitions into, between, and out of centered fullscreen and remains the exit preference for that active centered window; Reduce Motion in macOS always disables animation.

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help
--no-outer-gaps:: Remove the outer gaps when in fullscreen mode
--centered:: Display the fullscreen window centered on the monitor
--width <percent>:: With `--centered`, set the window width as a percentage of the selected monitor rectangle (default: `50%`)
--height <percent>:: With `--centered`, set the window height as a percentage of the selected monitor rectangle (default: `50%`)
--animation on|off:: With `--centered`, enable or disable the centered fullscreen transition (default: `off`)
--fail-if-noop:: Exit with non-zero exit code if already at the requested fullscreen target or already not fullscreen

--window-id <window-id>::
include::./util/window-id-flag-desc.adoc[]

// =========================================================== Arguments
include::./util/conditional-arguments-header.adoc[]

on, off::
`on` means enter fullscreen mode. `off` means exit fullscreen mode.
Toggle between the two if not specified
